Priority Queue Algorithms & Pseudocode

Academic algorithms with step-by-step logic designed for Data Structures coursework.

1. Insert Patient (Enqueue with Sift-Up)

Time Complexity: O(log n) 
Algorithm InsertPatient(queue, patient):
    // Assign sequence counter to ensure deterministic FIFO tie-break
    queue.sequenceCounter ← queue.sequenceCounter + 1
    patient.insertSequence ← queue.sequenceCounter

    // Append patient at the end of the Binary Heap array
    queue.heap.append(patient)
    currentIndex ← queue.heap.length - 1

    // Sift-Up to restore Max-Heap property
    While currentIndex > 0:
        parentIndex ← floor((currentIndex - 1) / 2)
        If ComparePriority(queue.heap[currentIndex], queue.heap[parentIndex]) > 0:
            Swap(queue.heap[currentIndex], queue.heap[parentIndex])
            currentIndex ← parentIndex
        Else:
            Break
    Return queue

2. Compare Priority (Composite Comparator)

Time Complexity: O(1) 
Algorithm ComparePriority(patientA, patientB):
    // Criterion 1: Higher Severity Level takes precedence
    If patientA.severity ≠ patientB.severity:
        Return patientA.severity - patientB.severity

    // Criterion 2: Earlier Arrival Time takes precedence (FIFO)
    If patientA.arrivalMinutes ≠ patientB.arrivalMinutes:
        Return patientB.arrivalMinutes - patientA.arrivalMinutes

    // Criterion 3: Lower Insertion Sequence Counter takes precedence
    Return patientB.insertSequence - patientA.insertSequence

3. Select Next Patient (Extract-Max with Sift-Down)

Time Complexity: O(log n) 
Algorithm SelectNextPatient(queue):
    If queue.isEmpty():
        Return Null

    highestPriority ← queue.heap[0]
    lastPatient ← queue.heap.pop()

    If Not queue.isEmpty():
        queue.heap[0] ← lastPatient
        SiftDown(queue, 0)

    Return highestPriority

4. Update Severity / Triage Level

Time Complexity: O(n + log n) 
Algorithm UpdatePatientSeverity(queue, patientId, newSeverity):
    targetIndex ← FindIndexById(queue.heap, patientId)
    If targetIndex = -1:
        Return False

    oldSeverity ← queue.heap[targetIndex].severity
    queue.heap[targetIndex].severity ← newSeverity

    If newSeverity > oldSeverity:
        SiftUp(queue, targetIndex)
    Else:
        SiftDown(queue, targetIndex)

    Return True

Coursework Academic Reflection

This project highlights the vital distinction between theoretical data structures and real-world mission-critical implementations. While a simple FIFO Queue satisfies fairness in non-urgent scenarios, applying it to emergency triage causes catastrophic patient endangerment. By employing a Binary Max-Heap with a composite deterministic comparator, we achieve both priority-based triage and strict FIFO fairness among equals in optimal $O(\log n)$ time.
